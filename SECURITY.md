# Security Policy

## Reporting a vulnerability

**Please do not open a public issue.**

Use GitHub's private vulnerability reporting:
<https://github.com/fukulow-app/fukulow/security/advisories/new>

Include what you did, what happened, and what you expected. A proof of concept
helps but is not required.

This is a hobby project maintained by one person. There is no guaranteed
response time, but reports are read.

## Supported versions

None yet. There has been no release. Once there is, this section will say which
versions receive fixes.
